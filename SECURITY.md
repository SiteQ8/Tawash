# Security

## Reporting a problem

If you find a vulnerability in Tawash, such as a way to make the web finder run code or a crafted DNS answer that breaks an export, email site@hotmail.com rather than opening a public issue. You will get an answer within a few days.

## Reporting a lookalike

Tawash lists candidates, not verdicts. If it shows you a lookalike that is clearly being used to defraud people in Kuwait, report it to the organisation being imitated and to the Kuwait National Cyber Security Center, and add it to the [Asli](https://asli.3li.info/) scam feed through its reporting form. Please do not open issues here that name domains as scams.

## Using it responsibly

Tawash exists to defend brands and the people who trust them. Checking whether a name exists in DNS is public, but `--web` fetches pages from sites that may belong to scammers, so run it from a network where that is acceptable, and keep watch results in a private place until a person has reviewed them.
